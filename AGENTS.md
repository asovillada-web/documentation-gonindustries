# Instrucciones para asistentes

Este repositorio es el handbook de Gon Industries para **Obby but You're a Rat**.

Antes de editar:

1. Lee `README.md`, `docs/vision-y-alcance.md`, `docs/decisiones.md` y `docs/estado-actual.md`.
2. Comprueba el contenido real antes de proponer cambios.
3. Conserva español latinoamericano natural; deja APIs y technical terms en inglés cuando sean más claros.

Reglas:

- Optimiza para que cinco principiantes aprendan, colaboren y terminen un MVP pequeño.
- Evita feature creep, arquitectura prematura y documentación que no apoye una tarea o decisión real.
- Una tarea necesita owner, reviewer, dependencias y Definition of Done observable.
- Investiga información actual o incierta; prioriza documentación oficial de Roblox y Discord.
- No guardes tokens, contraseñas, cookies ni claves.
- Cuando cambie una decisión importante, actualiza `docs/decisiones.md`.
- Documenta sistemas en `docs/sistemas/` solamente después de que existan o mientras se implementan.
