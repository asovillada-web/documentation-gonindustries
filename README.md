# Gon Industries — handbook del proyecto

Documentación viva de **Obby but You're a Rat**, el primer juego de Gon Industries.

Somos cinco amigos aprendiendo game development con Roblox Studio. Nuestro objetivo no es construir el sistema más grande: queremos aprender trabajando, organizarnos bien y terminar un juego pequeño, gracioso y jugable.

## Empieza aquí

No necesitas leer todo el repositorio. Usa esta ruta:

1. [Visión y alcance](docs/vision-y-alcance.md) — qué estamos construyendo y qué evitamos.
2. [Metodología](docs/metodologia.md) — cómo pasa una idea a `Done`.
3. [Equipo y roles](docs/equipo-y-roles.md) — quién coordina cada área.
4. [Estado actual](docs/estado-actual.md) — único step que importa ahora.

Cuando una tarea necesite más contexto, enlazará directamente el documento correspondiente.

## Fuente de verdad

- **Este repositorio:** metodología, requisitos, decisiones, roadmap y documentación de sistemas.
- **Discord:** conversación, anuncios, tickets y acceso rápido a esta documentación.
- **Roblox Studio:** experience, mapa, scripts, UI y assets del juego.
- **Repositorio de desarrollo:** bot y código basado en archivos cuando el equipo lo adopte.

Los documentos describen lo que decidimos o lo que realmente existe. No mantenemos arquitectura imaginaria ni copiamos conversaciones completas de Discord.
