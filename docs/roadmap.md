# Roadmap por gates jugables

Las fases terminan con evidencia observable. Las fechas se asignan después de conocer la velocidad real del equipo.

## Gate 0 — Fundación y ownership

Group, roles mínimos, experience privado, acceso de los cinco, Discord compacto, repositorio, bot de anuncio probado y reglas de trabajo entendidas.

**Salida:** todos pueden abrir el lugar correcto y saben dónde está la tarea activa; ningún secreto está versionado.

## Gate 1 — Vertical slice greybox

Default character, ruta de 30–60 segundos, hazard, respawn, checkpoint, goal y props de escala provisionales.

**Salida:** los cinco pueden terminarlo; Output sin errores nuevos; el playtest responde si la escala comunica “rata”.

## Gate 2 — Rat identity prototype

Probar el stand-in visual de rata, cámara, colisiones y una ruta contextual. Comparar cocina/despensa con otra opción solo si el primer test falla.

**Salida:** decisión registrada sobre escenario, escala y enfoque de personaje. Se descartan explícitamente alternativas.

## Gate 3 — Core MVP

Un solo recorrido de 3–5 minutos, checkpoints fiables, hazards legibles, meta/retry y feedback mínimo. Sin persistencia ni economía.

**Salida:** build privada completa de principio a fin con gameplay estable.

## Gate 4 — Art pass enfocado

Kit modular pequeño, rat hole, props clave, materiales y decoración que guían. Se reemplaza greybox solo donde mejora lectura/identidad.

**Salida:** escenario coherente sin empeorar colisiones ni performance.

## Gate 5 — Usabilidad y polish

Feedback audiovisual, UI mínima, onboarding de una frase, móvil/controller y primera revisión de performance.

**Salida:** una persona ajena al equipo entiende qué hacer sin explicación verbal.

## Gate 6 — QA y release

Multiplayer test, regression checklist, configuración de audience, permisos/publicación, assets y descripción. Release inicialmente controlado.

**Salida:** versión publicable, ownership correcto, checklist aprobado y changelog corto.

## Gate 7 — Decisión posterior

Con datos de playtest se elige: cerrar como proyecto terminado, pulir un problema concreto o ampliar una sola dimensión. No se promete contenido futuro antes de llegar aquí.
